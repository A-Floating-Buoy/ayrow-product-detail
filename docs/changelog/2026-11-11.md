- `tools/pdc-compare/before/`에 기준 화면 저장(엘릭서 10개 · 선베일 18개 섹션 × 4개 폭, 112장 · 36MB) — git 제외

**결정과 이유**
- 설계 · 규칙 · 단계는 스킨 레포 `docs/pdc-convention.md`에 둠(CSS · JS가 그 레포에 있음). 이 레포에는 상세 HTML 원본과 비교 도구만
- 스크린샷 · `node_modules`는 git 제외: 용량이 크고 다시 만들 수 있음
- 섹션은 순서 번호로 짝지음: 이전하면서 섹션 키 이름이 바뀌어도 비교 가능
- 테스트 상품은 관리자 "제품 복사"로 만든 것(사용자 확인) → 저장된 상세 HTML이 판매 상품과 같다고 보고 기준 화면을 그대로 씀
- 비교 잡음: 같은 페이지를 두 번 찍으면 40개 중 37개가 완전히 같고, 3개(Botanical 병 · Origin 들판)가 0.10% 이하로 다름 → 이 섹션들의 작은 차이는 움직임 때문으로 보고 눈으로 확인
